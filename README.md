## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the research, coding, and Workspace templates from `/templates`.
   - **Scripts:** Run the automation scripts from `/scripts` for Deep Research and Gems customization.
   - **Presets:** Apply the reasoning, multimodal, and integration presets from `/presets`.
4. Launch Gemini Advanced and follow the documentation to apply your configurations.
